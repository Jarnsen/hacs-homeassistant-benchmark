# Security policy

## Supported versions

Security fixes target the latest released 3.x version.

## Reporting a vulnerability

Please use the repository's private GitHub security advisory feature when
available. Do not open a public issue for a vulnerability that exposes secrets,
private Home Assistant data, or a practical attack path.

Include:

- the affected integration version;
- the affected Home Assistant version;
- reproducible steps;
- the expected impact;
- a minimal proof of concept, if safe.

Never include access tokens, cookies, public URLs containing credentials,
configuration files, or unredacted diagnostics.
